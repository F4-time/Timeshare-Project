# Archived Lovable migrations

These 19 migrations were generated by the original Lovable app and were applied
to the **old** Supabase project (`dqvixkolrnrhvikhmctn`).

They no longer describe the live database. On 2026-08-27 the schema was reset by
`MIGRATION_READY_CLEAN.sql`, which drops and recreates a smaller set of tables
and is now the baseline at `../20260827000000_baseline_clean_start.sql`.

Do **not** run these against the current project — they define a different,
larger schema (reservations, availability, room_types, ownership_contracts,
maintenance_fees, membership_benefits and more) and will conflict.

They are kept only as a reference for the tables the full build spec expects,
since the booking and inventory engines still need to be rebuilt.
